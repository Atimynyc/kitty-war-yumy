# 猫咪冻干保卫战 · PAW & PANTRY

一款竖屏单路推进的轻策略网页游戏。所有设备均为玩家在下方、电脑在上方；桌面和横放的手机也使用居中的竖向战场。双方通过自动投喂机生产猫粮、招募佣兵并争夺冻干仓库。

当前版本 **0.24.0**：新增菜单、战斗、首领背景音乐，以及招募、攻击、主炮、技能落地和胜负音效；右上角齿轮可打开独立「设置」框，音乐与音效音量分别保存。科技研究随兵种永久解锁（二阶第 3 关、三阶第 11 关）；双方基地猫持续呼吸、摆头、甩尾、抬爪，普通兵种强化蓄力、挥击和回弹。旧对局保留已完成及正在进行的研究。详细说明见 [科技解锁与动作优化](docs/科技解锁与动作优化.md)。

**0.23.0**：新增「我的猫咪」，可从首页或暂停菜单定制基地旁的玩家猫。支持 6 种品种、毛色与花纹、脸型、身型、耳朵、尾巴、眼睛、嘴巴、鼻子和爪子；提供动态预览、战场大小参考、随机、撤销和恢复默认。保存到本机后，开局、重开和续玩使用已应用的外观。详细说明见 [猫咪自定义实现记录](docs/猫咪自定义实现记录.md)。

角色图鉴可从首页或战斗暂停菜单进入，收录 16 位伙伴、8 种普通敌军和大胖橘首领。每份档案包含背景故事、完整形象、功能、技能机制、基础属性、招募条件及搭配 / 应对建议；未解锁角色也可阅读。详细说明见 [角色图鉴实现记录](docs/角色图鉴实现记录.md)。

伙伴随关卡永久解锁，按实际敌情逐步引入前排、远程、保护、控制与重装伙伴，第 24 关集齐 16 种。选关页说明新伙伴用途，招募卡区分关卡锁定和科技不足，胜利结算提示新伙伴。旧版已招募伙伴永久继承，0.18 / 0.19 未完对局可迁移续玩。完整解锁表、逐关克制分析及验证见 [兵种关卡解锁分析](docs/兵种关卡解锁分析.md)。

主动技能仍为急救罐头（35 能量）、猫薄荷（40）和毛球轰炸（70）；轰炸自动选择密集敌群并预告落点。设计见 [主动技能重设计](docs/主动技能重设计.md)。原有 24 项成就、续玩、八档产能、六章 30 关及三阶基地保留。

每五关切换美术场景，通关解锁下一关，首页可继续当前进度。原三关的成绩保留在选关页“经典三关成绩”。敌军设计与验收见 [docs/胖橘搜粮团实现记录.md](docs/胖橘搜粮团实现记录.md)。

## 启动

小红书小工具离线包使用 `npm run package:minitool` 构建、静态校验并打包，输出文件按当前版本命名为 `release/cat-protect-<版本号>-minitool.zip`。流程需要本机 Node.js 与 Python；已安装的规范位于 `.codex/minitool-zip-builder/`。`dist-minitool/` 为经典脚本、ES2017 / Chrome 61 目标的离线产物，打包不包含源码与开发依赖。

`npm run test:minitool` 检查平台存档的版本判断、迁移与失败处理；`node scripts/minitool-diagnostics.mjs` 只做现代浏览器中的受限加载诊断，不代表平台验收。上传同一 ZIP 后，仍须完成创服平台模拟器、Android 真机扫码、iOS 真机扫码验证。Chrome 61 CSS 兼容性和真机性能未实测。详细记录见 `release/小工具校验摘要.md`。

推荐 Node.js 24，最低使用支持 TypeScript 类型擦除的 Node.js 22.18。

```sh
npm install
npm run dev
```

## 玩法

- 双方初始 3000 基地耐久、240 猫粮和 12 猫粮/秒。敌方基地耐久归零即获胜。
- 点击佣兵卡招募。首局拥有士兵与玩具鼠，伙伴随关卡永久解锁：通关第 N−1 关即获得第 N 关新伙伴，重玩旧关仍保留。招募区显示“伙伴 N / 16”，已有伙伴排在前面，可上下滚动查看全部卡片；关卡锁定写明第几关，已获得但未研究写明所需科技。佣兵自动前进，遇敌战斗，消耗对应人口，退场后释放人口。人口上限为 24。
- 升级自动投喂机，共 8 档，产量依次为 12 / 18 / 22 / 26 / 30 / 34 / 38 / 42 猫粮每秒。七次升级费用为 120 / 160 / 220 / 280 / 340 / 400 / 480，后期回本更慢；敌我共用价格与收入，电脑按章节决定投资上限。局内二阶 / 三阶研究开放已永久获得的对应伙伴，同时强化主炮与轰炸；研究按钮显示本次实际新增招募资格。招募仍消耗猫粮、人口并遵守冷却。
- 双方各自开局拥有 50 能量，上限 100；急救罐头消耗 35，猫薄荷消耗 40，毛球轰炸消耗 70，共用本方能量池。击杀敌人回能，不随时间回能。
- 「急救罐头」为受伤伙伴回复 30% 最大生命，每只最多 240；「猫薄荷」使在场伙伴攻击力 +20%，持续 10 秒；「毛球轰炸」在密集敌群处预告落点，0.65 秒后造成范围伤害。没有有效目标时不能释放，也不扣能量。
- 电脑遵守同样的能量、猫粮、人口、科技和招募冷却规则，根据关卡节奏交替增援与整备；人口满员时等待空位。整备只暂停电脑招募，场上敌人和主炮继续战斗，双方照常产粮、研究与释放技能。击杀没有额外猫粮奖励。
- 双方主炮自动攻击 280 距离内最近的敌军，间隔 2.5 秒。科技一至三阶伤害为 32 / 55 / 85，主炮不消耗猫粮。
- 科技一至三阶分别显示纸箱营地、加固猫屋、冻干要塞；支付研究费用后等待 8 / 12 秒，完成时建筑与主炮一起升级。产能升级将小食盆依次换成单桶、双桶、输送投喂装置，再扩展为加高粮仓、自动分粮站、双塔粮仓、金爪粮食工坊。敌方外观独立跟随其科技与产能。
- 暂停时，战斗、收入和研究全部暂停。切到其他标签页时自动暂停，返回后手动继续。
- 首次点击或按键后启用声音；按 M 一键静音 / 恢复。点击右上角齿轮，在独立「设置」框的「声音」分区分别调节背景音乐和音效，调到 0 可单独关闭，设置保存在当前设备。打开设置时暂停战斗，关闭后恢复原状态；原本暂停时仍保持暂停。设置内可试听小窝音乐，切到后台时所有声音停止。支持 1× / 2× 对战速度，音乐保持正常节奏。

| 按键 | 操作 |
|---|---|
| 1—8 | 招募原八种单位 |
| Shift + 1—8 | 招募枪手、猫砂、功夫、刺客、雨伞、铃鼓、吸盘、拳套猫 |
| E | 升级投喂机 |
| T | 研究科技 |
| 空格 | 毛球轰炸（70 能量） |
| H | 急救罐头（35 能量） |
| C | 猫薄荷（40 能量） |
| P / Esc | 暂停或继续 |
| M | 开关音乐与音效 |

触屏通过按钮操作。游戏统一采用上下对抗的俯视地毯战场，底部为可上下滚动的四列招募卡以及一行基地升级按钮；急救、猫薄荷、轰炸位于战场最右侧，自上而下排列，按钮标明耗能。内容最大宽度 520 CSS 像素，宽屏居中；视口高度小于 560 时可上下滚动。旋转只改变尺寸，不切换玩法、不重置对局。

## 六章战役（0.12）

| 章节 | 关卡 | 场景 | 重点 |
|---|---|---|---|
| 阳光客厅 | 01–05 | 木地板、地毯、窗影与沙发 | 招募、经济、前后排 |
| 纸箱走廊 | 06–10 | 纸箱、胶带、猫抓板 | 盾卫、投手与法师 |
| 零食厨房 | 11–15 | 棋盘瓷砖、柜门、饼干罐 | 资源取舍与攻城 |
| 花园阳台 | 16–20 | 木平台、藤架、花盆 | 治疗、消耗与施法 |
| 月光天台 | 21–25 | 蓝灰地砖、围栏与暖灯 | 重骑与混编 |
| 冻干仓库 | 26–30 | 零食货架、罐头与包装路标 | 综合挑战与胖橘首领 |

- 一章展示五关，可预览未解锁关卡的编队与提示；获得一星即可继续，无需三星。每章完成后获得守护纪念章，第 30 关结束后可以重玩补星。
- 敌军逐步引入新兵种，部分关卡在 90 / 105 秒更换编队，第 27 关在 170 秒再次换阵。所有普通增援都使用同样的猫粮、人口、科技和招募冷却，不免费刷兵；入门对手的研究上限较低，玩家仍可研究到三阶。
- 胖橘在第 30 关敌方基地低于 30% 且仍存活时出场；直接摧毁基地仍判胜。章节边界、首领和换景均由数据配置驱动。
- 原存储键继续用于读取和保存，当前档案为 v5，兼容 v2 / v3 / v4；保存关卡、成就、未完对局、旧版继承伙伴及猫咪外观。新主线记录与经典三关记录分开，旧记录不冒充新关卡成绩，旧评分会注明，最快时间保留。
- 当前 180 场六策略对照覆盖 30 关，每关至少有一种正常资源混编策略可通关。模拟不代表真人胜率；入门关可短于三分钟，部分策略会拉成长局。详见 [30 关战役验收记录](./30关战役验收记录.md)。

## 角色图鉴（0.21）

首页点击「角色图鉴」，或对战暂停后进入。图鉴分为「守护小队」和「胖橘搜粮团」，点击任意角色打开档案，可连续翻阅上一位 / 下一位。返回列表保留原来的滚动位置；Esc 从详情返回列表，再返回入口页面。

每个角色都有独立的背景、称号与台词，并说明定位、技能、搭配或应对方法。属性读取当前游戏配置，显示生命、伤害 / 治疗、间隔、射程 / 治疗范围、移速、被击败时回能，以及科技、猫粮、人口、招募冷却。首领单独说明登场、横扫范围和位移免疫，不显示虚假的“免费招募”。

阅读不消耗资源、不解锁兵种。图鉴显示已拥有状态和加入关卡；敌军说明首次可能出现的关卡，实际登场仍受资源和研究影响。从暂停菜单进入后，战场、收入和研究都保持暂停，退出图鉴后手动继续。图鉴阅读位置不写入存档，本轮沿用 v4 档案和 0.20 战场规则。

## 主动技能与能量（0.19）

| 技能 | 耗能 | 效果 |
|---|---:|---|
| 急救罐头 | 35 | 全体受伤伙伴恢复30%最大生命，每只最多240；不修复基地 |
| 猫薄荷 | 40 | 施放时在场伙伴攻击力+20%，持续10秒；不影响新出兵、治疗和主炮 |
| 毛球轰炸 | 70 | 自动锁定最密集敌群，0.65秒后对半径140内敌人造成180/240/300伤害（科技一至三阶）；不伤友军和基地 |

开局50能量，上限100，无被动回能和额外技能冷却。满血不消耗急救，空场不消耗增伤或轰炸；猫薄荷刚生效的2秒内不能对完全相同的一批部队重复付费。毛球落下前不可重复轰炸；落点固定，可移动避开，遵循闪避和雨伞减伤。双方按同一价格支付，击杀返能仍如下表。

| 击杀目标 | 恢复能量 |
|---|---:|
| 发条玩具鼠 | 2 |
| 小鱼干士兵 | 4 |
| 毛球投手 | 5 |
| 纸箱盾卫 / 逗猫棒法师 / 奶妈猫 | 各 6 |
| 猫咪投石机 | 8 |
| 小狗骑士 | 20 |
| 猫咪玩具枪手 / 刺客猫 | 各 10 |
| 猫砂炸弹手 / 功夫猫 / 铃鼓猫 | 各 7 |
| 雨伞护卫猫 / 吸盘猫 / 拳套猫 | 各 8 |
| 大胖橘 Boss | 50 |

在支持的平台优先使用小红书本机存储接口，普通网页使用当前浏览器存储；这是设备本地缓存，不是账号云存档，不支持跨设备同步，清理缓存可能丢失。无法读取或来自未来版本的存档保持只读，避免覆盖。开发验收 `?qa` 使用独立键，不影响真实游玩进度；生产包不包含 QA 接口。

## 手机访问

手机和开发电脑连接同一局域网后，在项目目录运行 `npm run dev:lan`，用手机打开终端显示的 **Network** 地址。手机里的 `localhost` / `127.0.0.1` 指向手机自身，不能用它访问电脑服务。若无法连接，检查 Windows 防火墙是否允许 Node 在专用网络接入，以及路由器是否开启设备隔离。

此命令会把开发服务开放给局域网，仅在可信网络使用。正式发布使用 `npm run build` 生成的静态站点。

## 多尺寸与浏览器适配（0.4）

- 手机、折叠屏、平板、电脑和横放窗口：统一竖向战场，不再维护横屏模式。
- 宽屏留出两侧空间，短窗口保留至少 560 CSS 像素的完整游戏高度并允许滚动。
- 游戏区域使用实际可视高度，适应移动浏览器地址栏展开收起；通过 `viewport-fit=cover` 和 `safe-area-inset-*` 留出刘海与底部手势区域。
- 320 × 568 小屏、长屏、平板和横屏均纳入自动验收。特别矮的可用空间会隐藏佣兵卡插画、缩减辅助信息，保留所有招募和升级按钮。
- 主要触控目标至少 44 × 44 CSS 像素；方向变化时重排画面，不修改单位位置、资源、冷却或科技状态。
- Chromium 与 WebKit 引擎分别进行浏览器测试。Windows WebKit 测试不等同于真实 iPhone Safari，实机浏览器 / 微信内嵌浏览器仍需后续真机复核。
- 音频接口不可用时，静默降级，不影响开局与对战。
- 使用 Phaser 的 Canvas 2D 渲染，避免本次 WebKit 验收中复现的 WebGL 缩放后画面丢失。按钮内部内容仅在变化时更新，避免状态刷新打断点击。

WebKit 验收：先 `npx playwright install webkit`，再在 PowerShell 中执行 `$env:TEST_BROWSER='webkit'; npm run test:responsive`。结果和截图位于 `test-results/responsive/`。

本次覆盖范围与结果见 [移动端适配验收记录](./移动端适配验收记录.md)。

## 数值分析

[首轮数值平衡分析](./数值平衡分析.md) 按通常 3～5 分钟的目标比较兵种攻血、伤害击数、经济回本、阵容对抗与关卡运营。0.9.1 已应用推荐方案：法师 150 生命 / 28 伤害、骑士每击 150 伤害、三次产能升级费用 120 / 180 / 240；第三关节奏试案仍待单独验证。原始对照、CSV 与配置位于 `analysis/balance-2026-10-23/`，原始数值已保存为独立快照，报告包含复现命令。

开发模式下通过 `?qa` 才会暴露可修改状态的 `__catGame` 和确定性时间推进 `advanceTime`；生产构建不提供这些接口。只读的 `render_game_to_text()` 返回当前界面、关卡、单位状态、迟缓 / 增伤剩余时间、星星弹道与主炮状态，方便检查。

0.17 对照保存在 `analysis/pacing-0.17/`，校验并冻结 0.16 基线，沿用相同策略。103 项规则测试通过；前后各 540 场正常资源固定策略测试，当前 359 胜 / 167 负 / 14 超时，所有关卡在三个种子下均有可通关组合。已结束对局中位 236 秒，3–5 分钟占 211/526；满血胜局和部分支援长局仍待改善。不能将机器策略结果视为真人胜率。历史 0.16 数据保留在 `analysis/balance-0.16/`。
