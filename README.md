# 猫咪冻干保卫战 · PAW & PANTRY

一款竖屏单路推进的轻策略网页游戏。所有设备均为玩家在下方、电脑在上方；桌面和横放的手机也使用居中的竖向战场。双方通过自动投喂机生产猫粮、招募佣兵并争夺冻干仓库。

## 启动

推荐 Node.js 24，最低使用支持 TypeScript 类型擦除的 Node.js 22.18。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。默认地址为 `http://127.0.0.1:5173/`。

```sh
npm run build       # 类型检查并生成 dist/
npm run preview     # 预览生产构建
npm test           # 战斗规则自动测试
npm run test:browser # 浏览器验收，需要先启动开发服务
npm run test:responsive # 17 种屏幕尺寸与旋转、安全区验收
npm run test:animations # 八兵种动作、受击、死亡、暂停与旋转验收
node --experimental-strip-types scripts/balance.mjs # 使用正常资源在三关对比五种出兵策略
```

浏览器验收使用 Playwright Chromium。如果本机没有浏览器，请先运行 `npx playwright install chromium`。Windows 下也会自动尝试使用本机已有的 Playwright Chromium；可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定路径，通过 `GAME_URL` 指定开发服务器地址。截图保存在 `test-results/`。

## 玩法

- 双方初始 3000 基地耐久、240 猫粮和 12 猫粮/秒。敌方基地耐久归零即获胜。
- 点击佣兵卡招募。佣兵自动前进，遇敌战斗，消耗对应人口，退场后释放人口。人口上限为 24。
- 升级自动投喂机，产量依次为 12 / 18 / 26 / 36 猫粮每秒；研究科技，解锁盾卫、投手、法师、投石机、奶妈和小狗骑士，同时强化主炮。
- 「喵喵震退」推开己方基地附近的敌人并减速，冷却 45 秒。
- 电脑遵守同样的猫粮、人口、科技和招募冷却规则，根据关卡节奏持续招募直到基地被摧毁；人口满员时等待空位。击杀没有额外经济奖励。
- 双方主炮自动攻击 280 距离内最近的敌军，间隔 2.5 秒。科技一至三阶伤害为 32 / 55 / 85，主炮不消耗猫粮。
- 暂停时，战斗、收入和研究全部暂停。切到其他标签页时自动暂停，返回后手动继续。
- 音效默认关闭，点击右上角声音按钮开启。支持 1× / 2× 对战速度。

| 按键 | 操作 |
|---|---|
| 1—8 | 招募对应卡片的佣兵 |
| E | 升级投喂机 |
| T | 研究科技 |
| 空格 | 喵喵震退 |
| C | 释放猫薄荷 |
| P / Esc | 暂停或继续 |
| M | 开关音效 |

触屏通过按钮操作。游戏统一采用上下对抗的俯视地毯战场，底部为两行四列佣兵卡以及两行升级 / 法术按钮。内容最大宽度 520 CSS 像素，宽屏居中；视口高度小于 560 时可上下滚动。旋转只改变尺寸，不切换玩法、不重置对局。

## 小狗骑士（0.6）

猫咪穿上铠甲、骑着小狗作战的三阶终极近战兵。第八张招募卡为金色边框，按 **8** 或点击卡片招募。

| 属性 | 临时数值 |
|---|---:|
| 招募费用 / 人口 | 500 猫粮 / 6 人口 |
| 生命 / 每次攻击伤害 | 1800 / 140 |
| 攻击间隔 / 招募冷却 | 1.6 秒 / 12 秒 |
| 移速 / 近战射程 | 45 / 48 |

- 小狗四只脚分开运动，对角脚交替；铠甲骑手随坐骑轻微起伏，攻击时挺枪刺击。受击有回弹，死亡时整组退场并立即释放 6 人口。
- 骑士可以接受治疗和猫薄荷增伤，也会受到法师迟缓；单体近战伤害。外观铠甲通过高生命体现。
- 电脑三阶时如有足够猫粮和人口，会招募一名骑士；普通增援不会为了它无限等待。
- 数值集中在 `src/game/content.ts` 的 `UNITS.knight`，可继续调整。

## 星星法师与猫薄荷（0.5）

- **小鱼干士兵**：原小猫士兵更名，战场部件、招募卡和首页插画中的刀替换为小鱼干。
- **逗猫棒法师**：二阶解锁，110 猫粮、2 人口；生命 135、伤害 24、攻击间隔 1.6 秒、移速 40、射程 220，招募冷却 3.2 秒。基础数值为临时值。
- 法师挥棒发射星星，飞行约 0.32 秒后命中。命中使敌人攻速、移速降低 30%，持续 3 秒；再命中刷新，不叠加。攻速指攻击频率变为 70%，等效攻击间隔除以 0.7。迟缓有蓝紫色星环标记，与震退的移速降低取较强效果。
- 星星发射时记录攻击力。施法者死亡不取消已发射的星星；目标死亡时星星消散，不转移目标。建筑受到魔法伤害，不施加迟缓。
- **投石机**：落点周围逻辑距离 70 内所有敌军受伤害，包括边界，没有友军伤害；范围不受画面中装饰性的行列错位影响。保留即时结算并显示范围冲击圈。
- **猫薄荷**：无猫粮消耗；释放时在场的我方存活单位攻击力 +20%，持续 10 秒，冷却 45 秒。后续新招募的单位无加成。投石机范围伤害和兵种对基地伤害同样增加；治疗量和基地主炮不增加。无在场单位时不能释放，也不消耗冷却。电脑遵循相同规则。
- 绿叶表示猫薄荷增伤；按钮显示当前增伤人数、剩余时间和冷却。所有状态、弹道随暂停冻结、随倍速推进，重开清空。
- 可调数值集中于 `src/game/content.ts` 的 `STAR_MAGIC`、`CATNIP`、`UNITS.mage`；规则和浏览器验收见 [兵种与法术验收记录](./兵种与法术验收记录.md)。

## 分部件动画（0.4）

- 小猫身体、双脚、双手与武器分别绘制；走路时双脚交替、身体轻微起伏、双手反向摆动。
- 士兵挥鱼干、盾卫盾击、投手拉弦、法师挥逗猫棒、奶妈举杖；玩具鼠转动发条，投石机摆动投掷臂，车轮随行进变化。
- 受击时身体短暂压缩和回弹；死亡立即释放人口，画面继续翻倒、冒星星并在 0.8 秒内淡出。
- 除星星弹道外，保留原有即时伤害规则：接敌首击直接出手，后续攻击在冷却最后 0.16 秒蓄力，命中姿势与伤害事件同步。
- 动作跟随战斗时间与实际移动距离，暂停时冻结，倍速同步；重开清理所有退场角色。系统减少动态效果开启时取消摆动、挥击和翻倒，保留淡出。

## 首页、关卡与操作（0.3）

打开游戏先进入独立首页；未点击开始前，时间、猫粮、研究和敌方出兵均不推进。首页可以直接开始或进入关卡选择，三关均可挑战。

| 关卡 | 难度 | 首波敌军出发 | 特点 |
|---|---|---|---|
| 阳光客厅 | 入门 | 24 秒 | 较长准备期，适合先升级投喂机再出兵 |
| 纸箱走廊 | 标准 | 16 秒 | 更频繁增援，鼓励前排与远程配合 |
| 冻干保卫线 | 挑战 | 10 秒 | 更快出兵和更早的经济/科技投资 |

白色角色卡用于出兵，绿色模块升级产能，紫色模块研究科技，橙色按钮发动「喵喵震退」，浅绿色法术按钮释放「猫薄荷」。科技按钮展示主炮伤害变化；猫粮不足的兵种卡展示需要等待的秒数。

| 兵种 | 猫粮 | 招募冷却 |
|---|---:|---:|
| 发条玩具鼠 | 25 | 0.8 秒 |
| 小鱼干士兵 | 50 | 1.2 秒 |
| 纸箱盾卫 | 90 | 2.5 秒 |
| 毛球投手 | 85 | 2.4 秒 |
| 逗猫棒法师 | 110 | 3.2 秒 |
| 猫咪投石机 | 160 | 4.5 秒 |
| 奶妈猫 | 130 | 4 秒 |
| 小狗骑士 | 500 | 12 秒 |

科技研究费用为 150 / 280 猫粮，耗时 8 / 12 秒；投喂机升级费用为 120 / 220 / 340 猫粮。开局可以先升级产能，再连续招募两只小鱼干士兵。

暂停后可重开、返回选关或首页；结算后可重试、选关，获胜后还能进入下一关。胜利星级（剩余耐久 ≥70% 为三星、≥35% 为二星）和最佳通关时间保存在当前浏览器。浏览器禁用存储时依然可以正常游玩，但记录不会跨刷新保留。当前战斗本身不跨刷新保存。

## 手机访问

手机和开发电脑连接同一局域网后，在项目目录运行 `npm run dev:lan`，用手机打开终端显示的 **Network** 地址。手机里的 `localhost` / `127.0.0.1` 指向手机自身，不能用它访问电脑服务。若无法连接，检查 Windows 防火墙是否允许 Node 在专用网络接入，以及路由器是否开启设备隔离。

此命令会把开发服务开放给局域网，仅在可信网络使用。正式发布使用 `npm run build` 生成的静态站点。

项目已包含 GitHub Pages 自动部署工作流。创建公开仓库，在 Settings → Pages 中选择 GitHub Actions，然后将源码推送到 `main`，即可发布为手机可直接访问的网址。完整首次上传、发布和更新步骤见 [GitHub 部署说明](./GitHub部署说明.md)。

## 多尺寸与浏览器适配（0.4）

- 手机、折叠屏、平板、电脑和横放窗口：统一竖向战场，不再维护横屏模式。
- 宽屏留出两侧空间，短窗口保留至少 560 CSS 像素的完整游戏高度并允许滚动。
- 游戏区域使用实际可视高度，适应移动浏览器地址栏展开收起；通过 `viewport-fit=cover` 和 `safe-area-inset-*` 留出刘海与底部手势区域。
- 320 × 568 小屏、长屏、平板和横屏均纳入自动验收。特别矮的可用空间会隐藏佣兵卡插画、缩减辅助信息，保留所有招募和升级按钮。
- 主要触控目标至少 44 × 44 CSS 像素；方向变化时重排画面，不修改单位位置、资源、冷却或科技状态。
- Chromium 与 WebKit 引擎分别进行浏览器测试。Windows WebKit 测试不等同于真实 iPhone Safari，实机浏览器 / 微信内嵌浏览器仍需后续真机复核。
- 音频接口不可用时，静默降级，不影响开局与对战。
- 使用 Phaser 的 Canvas 2D 渲染，避免本次 WebKit 验收中复现的 WebGL 缩放后画面丢失。按钮内部内容仅在变化时更新，避免状态刷新打断点击。

WebKit 验收：先 `npx playwright install webkit`，再在 PowerShell 中执行 `$env:TEST_BROWSER='webkit'; npm run test:responsive`。结果和截图位于 `test-results/responsive/`。

本次覆盖范围与结果见 [移动端适配验收记录](./移动端适配验收记录.md)。

## 首版内容

- 一张客厅地图，八种佣兵，三级科技，四级投喂机。
- 近战接敌、远程攻击、投石机范围伤害和攻城加成、最多三个友军的治疗。
- 三个难度的持续增援电脑、独立首页 / 关卡选择 / 暂停 / 胜负结算 / 重开流程。
- 本地矢量角色和场景、战斗特效、可切换的合成音效。
- 入门关策略模拟约 1.5～2 分钟，标准与挑战关约 2～5 分钟，具体取决于阵容和升级策略；平衡仍可继续根据实玩调整。

## 项目结构

```text
src/
  game/
    content.ts       兵种、法术、经济、科技与主炮配置
    levels.ts        关卡节奏、难度配置与通关存档校验
    simulation.ts    独立于画面的对战规则和电脑决策
    BattleScene.ts   竖屏 Phaser 场景、血条与特效
    UnitView.ts      分部件角色、兵种动作与退场
    unit-motion.ts   根据战斗时间和移动距离计算动作
    unit-art.ts      身体、脚、手与武器的 SVG 素材
    weapon-art.ts    战场与卡片共享的小鱼干 / 逗猫棒素材
    knight-art.ts    四爪小狗坐骑、铠甲骑手与骑枪部件（卡片 / 战场共用）
    projection.ts    单路战斗进度到竖屏画面的映射
    audio.ts         本地 Web Audio 合成音效
  art.ts             原创 SVG 角色与客厅插画
  portrait-art.ts    竖屏基地插画
  responsive.css    可用视口、安全区及统一竖屏布局
  ui/viewport.ts    动态可视高度与紧凑密度
  ui/menus.ts        首页、关卡卡片与进度展示
  experience.css    菜单与按钮用途样式
  main.ts            DOM 界面、页面导航、操作绑定和状态展示
  style.css          主题、桌面和手机布局
tests/
  simulation.test.ts 战斗规则测试
  viewport.test.ts   布局选择与竖屏投影检查
scripts/
  playtest.mjs       浏览器操作验收与截图
  balance.mjs        策略模拟和局时参考
  responsive-playtest.mjs 多尺寸、旋转和跨浏览器检查
  animation-playtest.mjs  八兵种动画与生命周期检查
游戏设计方案.md       原始玩法设计
```

技术栈为 Phaser 3、TypeScript、Vite。所有插画由项目内 SVG 绘制，音效由 Web Audio 合成，不依赖远程图片、字体或音频服务。

开发模式下通过 `?qa` 才会暴露可修改状态的 `__catGame` 和确定性时间推进 `advanceTime`；生产构建不提供这些接口。只读的 `render_game_to_text()` 返回当前界面、关卡、单位状态、迟缓 / 增伤剩余时间、星星弹道与主炮状态，方便检查。
