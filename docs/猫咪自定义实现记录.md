# 我的猫咪 · 0.23

2026-10-27。首页与战斗暂停菜单新增「我的猫咪」。定制对象是我方基地旁代表玩家的猫，所有已开放关卡共用当前外观；军队兵种保留各自的角色美术，外观不参与战斗数值计算。

## 预览与关卡

- `cat-appearance.ts` 管理外观数据、预设、深复制和输入校验。仅允许已知枚举与六位 HEX 色值，异常字段回退，避免无效 SVG。
- `base-cat-art.ts` 生成 11 层素材，编辑预览和 Phaser 角色使用相同路径、颜色、锚点；品种、身型、部件形状均产生实际差异。
- 编辑页 SVG 按现有 `baseCatMotion` 计算呼吸、头部、耳朵、尾巴、眨眼和抱罐动作。减少动态效果时静止；退出停止预览动画。战场大小按钮提供约 64 CSS 像素参考，实际战场随屏幕调整。
- 战场由 `BaseCatView` 解码当前 11 张图片后一次替换玩家角色，再销毁旧纹理。生成中保留原猫，失败可重试，不预生成所有组合，重复换装不累积旧素材。
- 等待场景就绪与外观应用完成后开放开始按钮；新开 / 重开 / 续玩直接使用已应用角色。暂停菜单内编辑不推进战斗、资源或研究，返回仍然暂停。
- 320px 短屏使用紧凑预览，普通手机上方固定预览、下方选项独立滚动，宽屏双栏；返回和保存始终可达。

## 存档

档案升级至 v5，`cat` 与关卡、成就、兵种继承和未完对局一起保存。v2 / v3 / v4 自动迁移，缺少外观使用默认灰白猫；未来版本、损坏档案或读取失败继续沿用只读保护。战斗保存规则仍为 0.20，不改变对局格式和模拟逻辑。

通过现有存储适配器优先写小红书本机存储，网页写浏览器存储。保存成功才显示成功；写入失败明确提示当前已应用但未持久化，保留重试入口。只读档可以试搭，但不能保存。不是跨设备云存档。

## 验证入口

- `npm test`：旧档迁移、十项外观持久化、异常字段回退、未来版本保护、战斗状态一致、保存失败与重试，以及原有规则回归。
- `npm run test:cat-editor`：真实页面操作六品种与十项字段、草稿隔离、退出、保存、刷新、暂停、重开、纹理释放、失败重试、四尺寸和减少动态效果；设置 `TEST_BROWSER=webkit` 检查 WebKit。
- `npm run test:cat-idle`：原有双猫动画、姿态续玩、表情和首领离席回归。
- `npm run build`、`npm run build:minitool`、`npm run audit:minitool`；`node scripts/minitool-diagnostics.mjs` 覆盖 Chromium / WebKit 和平台能力降级，包含编辑、原生存储桩和动态换装。

已通过 152 项规则测试、Chromium / WebKit 定制专项、Chromium 原待机回归、网页与小工具构建、静态审计和四条小工具诊断路径。颜色控件不受支持时提供经过校验的色号输入。
