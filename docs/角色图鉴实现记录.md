# 角色图鉴 · 0.21.0

2026-10-26。按“新增角色介绍页面，详细介绍每个角色的背景、功能和属性”的需求，新增完整角色档案。

## 内容与入口

- 首页「角色图鉴 · 25 份档案」与暂停菜单「角色图鉴」进入同一个独立页面。
- 守护小队：16 位伙伴，按解锁关卡排列；搜粮团：8 种普通敌军与大胖橘首领。每一位都有单独撰写的故事、称号、台词、用途、建议和注意事项。
- 详情展示完整插画、定位、加入状态、背景、本领、属性与招募条件，支持连续翻阅；未解锁角色不隐藏内容，也不会因为阅读而获得招募资格。
- 设计沿用奶油色纸张、鼠尾草绿与陶土色阵营配色。列表两列，详情单列，顶部固定返回栏；无需在战场上阅读长说明。

## 属性与机制口径

基础属性与数值由 `src/game/content.ts` 的 `UNITS`、`SPECIAL`、`STAR_MAGIC`、`ORANGE_BOSS` 和 `ENERGY_REWARDS` 生成。解锁使用 `unit-unlocks.ts`，敌军首次可能出现的关卡由关卡编队、科技上限及重骑 / 首领条件推导。

普通角色展示生命、单次伤害或治疗量、攻击 / 治疗 / 鼓舞间隔、对应范围、移动速度、被击败时对方获得的能量，以及科技、招募猫粮、人口和冷却。数字为基础值，实际交战会受状态、蓄力与弹道影响，不换算成容易误导的固定实战秒伤。

首领不显示费用 0 或科技 99，而是说明第 30 关敌方基地低于 30% 且仍存活时登场、入场保护、抬爪 / 停顿 / 横扫、命中范围和击退。仍以摧毁基地作为胜利条件。

文案明确机制边界：雨伞不减免近战、不解控；铃鼓不攻击、鼓舞不叠加；枪手不禁疗或优先攻击治疗；刺客只在首次非致死伤害后隐身，不自动追杀后排；吸盘射程有限且不能指定目标；拳套不能推走首领。敌方第 16 关起允许出现治疗兵，不代表该关每次都一定招出。

## 交互与存档

列表返回保留滚动和角色按钮焦点，详情标题获得键盘焦点，首末页禁用无效翻页。Esc 逐级返回，玩法指南弹窗关闭后仍停留当前档案。短窗口和横屏可滚动，文字不截断，角色图片保留全身和装备。

从战斗暂停菜单进入时保存已有对局，阅读期间不推进时间、收入、研究或技能状态，也不接受战斗快捷键。返回仍停留暂停菜单，手动继续；阅读期间刷新后可从首页恢复原检查点。图鉴状态只保存在本次页面会话，不修改兵种解锁或新增存档格式。版本升至 0.21.0，战场规则继续使用 0.20.0。
