# 兵种关卡解锁分析

2026-10-26，已在 **0.20.0** 实现。基于原 0.19.0 的 30 关、16 种我方单位和三种主动技能，先比较解锁顺序、核实敌军实际招募时间，再将永久解锁接入关卡、招募、研究提示和存档。关卡编队、兵种数值及科技费用保持原有配置。

## 已实现规则

以“到达该关，在开战前解锁；本局研究到对应科技后可以招募”为规则。例如通关第 7 关后即可获得雨伞护卫，在第 8 关研究二阶后招募，不必先打赢第 8 关。

解锁是永久进度，重玩前面的关卡不会重新锁回去；通关一星即可继续解锁，不要求三星。关卡解锁决定有哪些伙伴，局内科技决定什么时候能派上场，猫粮、人口和招募冷却继续生效。

章节守关第 5 / 10 / 15 / 20 / 25 / 30 关不首次解锁单位，用来检验已经学习的组合。第 24 关前集齐 16 种，第 25–30 关保留完整阵容选择。

## 为什么不能只看关卡标题

配置中敌军科技上限在第 1–3 关为一阶、第 4–12 关为二阶、第 13 关起为三阶；法师第 8 关起、攻城车第 13 关起、治疗第 16 关起、重骑第 22 关起才进入允许的编队。

但“进入编队”不等于“这一局一定招出来”。敌人还需要研究科技、积攒猫粮、等待轮换及招募窗口，队伍被压制或基地提前被推平时可能完全看不到新兵。

初稿测试采用同一随机种子、五种正常资源打法。限制可用兵种后，第 13 关仅 1/5 场实际招出攻城车，第 16 和 17 关都为 0/5 场招出治疗兵；第 18 关为 5/5 场，第 22 关为 5/5 场招出重骑。因此最终建议将枪手的解锁从第 16 关移至第 18 关。第 13 关吸盘的主要教学目标写为已实际出现的法师和弹弓，不把未必见到的投射车当作唯一理由。这些频率只描述这五种脚本打法。

如果坚持第 16 关就是“第一次治疗敌人教学”，还需要调整该关真实的研究与付费招募优先级，再验证前排足够、治疗确实上场及玩家有时间研究对应兵种。本方案先按现有关卡实战安排，不依赖免费刷出敌人。

## 克制关系的边界

- 盾卫靠高生命承伤，没有嘲讽或自动拦截弹道；仍需要合理出兵顺序。
- 雨伞的 45% 减伤持续 3 秒，每 6 秒启动一次，只保护范围内获得状态的伙伴；不会持续免疫远程，也不免疫迟缓。
- 吸盘优先选择射程内最近的远程敌人，不能指定攻击治疗或攻城车。它的射程 260 小于投射车的 310，需要前排护送靠近；拉近 140 也不保证目标立即进入 65 的开火盲区。
- 枪手不会优先瞄准治疗兵，也没有禁疗；其价值是射程、单发输出和配合吸盘。猫薄荷强化的是攻击伤害，铃鼓强化的是攻击频率，二者可以配合。
- 铃鼓不会解除迟缓。30% 迟缓与 25% 鼓舞同时生效时，攻击频率约为原来的 87.5%，并非恢复满速。
- 刺客只有首次非致死伤害后的 3 秒隐身，不会自动搜寻治疗兵；应教穿线和利用进攻窗口，不应写成“治疗克星”。
- 拳套能击退普通重骑，首领大胖橘免疫位移；重骑没有可被持续打断的蓄力机制。对首领需要前排、远程、迟缓、减攻和救场技能协同。

部分解锁承担明确反制，部分承担学习阵容搭配。每个教学关都应允许至少一种旧兵种方案通关，新兵应让应对更清楚，而不是形成“没买指定卡就无法过关”的门槛。

## 研究、提示和存档的落地边界

首次二阶伙伴在第 3 关、首次三阶伙伴在第 11 关。科技费用和耗时沿用 150 / 280 猫粮、8 / 12 秒，不额外免费升级。第 1、2 关研究仍可提高主炮与轰炸伤害，研究按钮和完成提示按实际拥有的伙伴计算；没有新招募资格时说明主炮与轰炸强化。

选关页显示“本关新伙伴＋用途＋所需科技及猫粮”；进场用短提示介绍，在招募卡标记“新”。锁定卡写“第 N 关”，已经满足关卡条件但未研究时写“需二阶/三阶”。已有伙伴排在前面，未获得的按解锁关卡排列，保留原快捷键映射。招募区显示“伙伴 N / 16”，胜利结算提示真正新加入的伙伴，重复通关不重复发奖。卡片点击、键盘快捷键和模拟层均使用同一校验。

永久解锁按连续通关记录推导：通关第 1 至 N−1 关，就算达到 N 关。不能用孤立的最高关卡记录跳过中间关。选中更高关也不能解锁单位。

档案升级到 v4，沿用原存储键，兼容 v2 / v3。迁移保留关卡成绩、成就及有招募记录的伙伴；旧对局当前部队与招募统计也合并到继承集合。0.18 / 0.19 未完对局在本局保持全部伙伴可招募，随后实际招募的伙伴继续永久继承；结束或重开后采用“关卡进度＋继承伙伴”。新规则对局保存本局阵容与规则版本，恢复后先暂停。未来版本仍保留只读保护；不兼容战场提示会保留到玩家开始新局，避免迁移保存状态掩盖提示。

实现集中在 `src/game/unit-unlocks.ts`。页面开局明确传入永久阵容，`Battle.summonReason` 在科技、资源、人口和冷却之前拦截未解锁伙伴。独立战斗模拟没有账号信息，未传阵容时保留全兵种默认值，供单兵规则测试和旧数值工具使用；本轮首通分析明确传入各关真实阵容，不使用这个默认值绕过限制。

敌军继续使用各关编队与科技条件，不读取玩家的永久解锁记录。玩家后期重玩前面关卡可使用更多伙伴，是永久解锁带来的正常回报；首通数值验证必须只允许当时进度可获得的伙伴。

## 验收范围

1. 第 N−1 关结束即可看到新伙伴，第 N 关开战前拥有招募资格；本局科技不足时仍不能招募。锁定尝试不扣猫粮、不占人口、不计成就。
2. 首通只用已解锁阵容，30 关每个测试种子至少存在一种正常资源策略能过；单独保留失败和超时，不用未解锁兵种兜底。
3. 第 4 / 8 / 13 / 18 / 22 关记录对手真正招出的对应威胁，以及玩家第一次能够招募应对兵种的时间；研究与攒粮应留出准备窗口。
4. 教学提示按实际机制写，不宣称雨伞解控、刺客点杀治疗、枪手禁疗或拳套推走首领。
5. 低关重玩保留永久兵种，旧存档继承已经使用的伙伴；旧对局续玩、暂停、重开、下一关和键盘操作使用一致的兵种集合。
6. 所有 16 种最终可获得，相关收集和技能成就仍然可达；手机锁卡文案、滚动、研究提示以及新兵提示不遮住战场。

## 复现分析

`scripts/analyze-unit-unlocks.mjs` 将各关阵容传入正式 `Battle.reset`，由真实招募校验拒绝未解锁伙伴；分析子类只记录首次实际招募时间。五套固定策略遇到未解锁角色时按脚本内公开的替代表改用较早伙伴；不增加资源，不改变敌方，也不改兵种数值。达到 600 秒记为超时。

```sh
node --experimental-strip-types scripts/analyze-unit-unlocks.mjs --out=draft-rerun
node --experimental-strip-types scripts/analyze-unit-unlocks.mjs --schedules=observedEncounters --seeds=1234,20261025,8675309 --out=implemented-rerun
npm test
npm run test:unlocks
# PowerShell 下切换引擎：$env:TEST_BROWSER='webkit'; npm run test:unlocks
```

初稿对照保存在 `analysis/unit-unlocks-2026-10-26/draft-comparison.json`，包含不限制兵种、枪手较早解锁和按编队主题解锁三种安排，每种 150 场。推荐表对应脚本中的 `observedEncounters`。报告记录源码指纹、各次付费招募的首次时间、具体招募种类、胜负和超时；运行前后检查源码未变化。

## 实施结果与限制

- `proposed-three-seeds.json` 保留方案阶段的 450 场；`implemented-three-seeds.json` 为接入正式招募限制后的 450 场。逐场胜负、时间、双方基地耐久一致，源码指纹验证通过。30 关 × 3 个种子均至少有一种固定策略胜出，没有使用未解锁单位兜底。
- 正式结果为 **357 胜、70 负、23 超时**。胜局中位 180 秒，范围 88–563 秒；其中 121 场胜局落在 180–300 秒，351 场基地满血。仍有长局与满血胜局偏多的问题，不能视为真人胜率或完整平衡结论。
- 全量 **147 项规则测试通过**，覆盖连续进度、继承、科技与资源限制、无效尝试不扣费、存档验证和旧版本迁移。Chromium / WebKit 解锁专项均通过：预览不解锁、按钮与快捷键限制、第 2 关结算获得投手、第 3 关真实研究招募、第 8 关雨伞、暂停续玩、重开、旧阵容迁移和后期重玩第 1 关。
- 已检查 320px / 390px / 横屏 / 桌面布局，以及新伙伴结算、克制提示与继承兵种排序。完整玩法、30 关连续推进、四尺寸响应式通过。标准开发客户端正常资源完成三次士兵招募、猫薄荷扣 40 能量和约 26 秒推进，截图与文本状态已核对，无错误文件。
- 浏览器证据在 `test-results/unit-unlocks/`，正常资源客户端在其 `skill-final/` 子目录。部分界面截图使用明确注入的战场或进度，只验证布局与操作，不用于证明正常资源通关。
- 成就与续玩回归在 Chromium / WebKit × 浏览器存储 / 原生接口桩四条路径通过；修复迁移保存覆盖不兼容战场提示的问题。最终 TypeScript、网页构建、小工具构建与静态审计通过，双引擎生产 / 降级四条受限加载诊断通过；保留既有 Phaser 大包提示。
