# 背景音乐与音效 · 2026-10-28

本次补齐声音体验，保持 0.24 战斗规则与存档格式。

## 游戏内体验

- 首次点击或按键后开始播放。首页 / 选关使用轻快的小窝旋律，进入战斗加入低音和轻打击乐，大胖橘出场后切换更紧凑的节奏；每段有 16 小节的循环变化。
- 招募、产能升级、开始研究、研究完成、治疗、增伤、轰炸预告与落地、普通近战、远程、魔法命中、主炮、基地受击、首领登场 / 横扫，以及胜利 / 失败都有声音反馈。
- 点击右上角齿轮打开独立「设置」框，在「声音」分区调整总开关、背景音乐和游戏音效。背景音乐默认 38%，音效默认 65%，分别拖动到 0 可单独关闭；M 一键静音 / 恢复。
- 战斗中打开设置会暂停，可试听小窝旋律；关闭、完成或 Esc 返回时恢复原先运行状态，原本暂停的对局保持暂停。切换后台时全部静音，回来后关闭设置也不会自动继续战斗。
- 首页 / 暂停菜单的入口简化为「成就」和「图鉴」，配奖杯 / 书本 SVG 图标；结算的成就入口同步。成就数量保留在按钮悬浮提示，详细进度在成就页查看。
- 音乐使用独立音频时钟，1× / 2× 游戏速度不改变音乐的节奏或音高。重开、恢复、反复刷新界面不会叠加背景音乐或重播旧事件。

## 实现

- `src/game/audio.ts`：原创音符谱与合成器，柔和拨弦 / 钟琴、三角波低音、滤波噪声打击乐；独立音乐 / 音效总线、压缩器、短前瞻排程、声部清理和音效限频。不使用外部音频文件或网络服务，离线包无需增加资源类型。
- `src/game/battle-audio.ts`：观察现有特效 ID、轰炸落地状态、科技、基地生命和首领状态，逐帧去重；不修改模拟、随机序列或战斗存档。
- `src/ui/audio-settings.ts`、`src/audio.css`：声音设置与快捷键入口。通过现有平台存储适配保存到 `paw-pantry-audio-v1`；QA 使用独立键。读取 / 写入失败不阻止游戏，保存失败给出提示。
- 浏览器缺少 Web Audio 或设备创建失败时退回无声运行；真实手势才请求启动音频。开发热更新时释放旧声音实例；离线构建剔除热更新接口。

## 验证

- `npm test`：155 / 155 通过。
- `npm run test:audio`：Chromium 实际音频信号验证通过，覆盖三种配乐、音效试听、双音量、总静音、暂停、后台、刷新保存、恢复、事件去重、延迟轰炸、主炮、研究完成、治疗 / 增伤、基地受击、首领与胜利单次播放、声部释放、设备异常降级。
- 静音、音乐单独关闭和暂停后的采样峰值均为 0；密集音效测试峰值约 0.785，低于数字削波阈值 1。音量与响度仍会受系统、扬声器和用户设置影响。
- 声音设置覆盖 320×568、390×844、844×390、1440×900；已查看首页、320px 暂停入口、设置和首领实际截图。
- 当前 Windows Playwright WebKit 没有 `AudioContext` / `webkitAudioContext`。设置、招募、暂停、持久化与恢复的无声降级测试通过，**未验证该内核的实际声音输出，也不代表 iOS 真机声音验收**。
- 既有完整浏览器流程通过；标准 develop-web-game 客户端完成三次正常招募与约 28 秒战斗，无错误文件。正式构建、离线构建、静态审计及双引擎生产 / 降级四组受限加载诊断通过。
