# 胖橘搜粮团 · 0.13.0

本轮把敌军从我方兵种的换色版本改成独立阵营：橘色条纹、红围巾、厨房用具和零食包装。八种普通敌军接入实际战斗、选关封面、关卡敌军预览和玩法指南图鉴。

![游戏内实际造型总览](../test-results/enemy-faction/chromium-roster.png)

| 现有战斗职责 | 我方 | 敌方 | 主要辨识点 |
|---|---|---|---|
| 快速突击 | 发条玩具鼠 | 罐头侦察车 | 罐头机身、红色轮组、探头 |
| 均衡近战 | 小鱼干士兵 | 饼干棒打手 | 红头带、大饼干棒 |
| 前排守护 | 纸箱盾卫 | 锅盖卫兵 | 钢盆头盔、圆锅盖盾 |
| 远程输出 | 毛球投手 | 饼干弹弓手 | 折纸零食帽、饼干弹丸 |
| 迟缓控制 | 逗猫棒法师 | 铃铛干扰师 | 红色兜帽、双铃、金色铃音光环 |
| 范围攻城 | 猫咪投石机 | 零食投射车 | 零食木箱、汤勺抛射臂 |
| 治疗支援 | 奶妈猫 | 罐头补给员 | 补给包、开盖罐头、分享食物动作 |
| 终极重骑 | 小狗骑士 | 小猪重骑兵 | 粉色小猪、四只蹄子、餐叉长枪 |

普通猫兵有正面、侧面、背面，重骑保留独立四蹄、骑手、双手八部件。车辆继续在地面平面转向。敌方弹丸为饼干，干扰师发射铃音，治疗保留通用绿色治疗标记。慢速状态仍使用蓝紫色状态环，避免混淆。

阵营名、敌方血条、基地旗帜和大胖橘围巾同步为暖红色。本轮仅协调基地颜色，原三阶基地与主炮造型方案仍属后续迭代。

## 实现边界

- 共用既有 `UnitKind` 职责、攻血、射程、人口、猫粮、招募冷却、科技和击杀回能；敌军美术与展示身份独立。
- `simulation.ts`、`content.ts`、`levels.ts` 的 SHA-256 与 0.12.0 留档完全一致。`campaign.ts` 只更新敌军相关名称和提示，30 关时序、编队和难度参数未变。
- 第 30 关首领机制及旧进度存储格式保持兼容。敌军专属新机制尚未加入，不把外观更新描述成新增玩法。
- 所有新素材由本地 SVG 部件绘制，与现有 Phaser / Canvas 资源管线一致，无外部图片服务。
