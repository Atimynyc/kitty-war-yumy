# 主动技能重设计 · 0.19.0

2026-10-26，已实现。用户要求删除作用偏弱的震退，增加两个主动技能，并重新设计耗能。最终提供急救、增伤、范围爆发三种选择。

## 技能与操作

| 技能 | 耗能 / 快捷键 | 实际效果 | 使用时机 |
|---|---|---|---|
| 急救罐头 | 35 / H | 立即为全体存活受伤伙伴回复最大生命的 30%，每只最多 240，不超过缺失生命；不修复基地 | 前排残血、昂贵单位即将阵亡时保住队伍 |
| 猫薄荷 | 40 / C | 释放时在场伙伴攻击力 +20%，持续 10 秒；不强化治疗、主炮或之后招募的单位 | 部队已经接敌、准备集火推进时使用 |
| 毛球轰炸 | 70 / 空格 | 自动选择最密集敌群，显示固定落点；0.65 秒后对半径 140 内敌人造成 180 / 240 / 300 伤害，按释放时科技一至三阶确定 | 敌军后排聚集、突破前排或缓解基地压力 |

所有技能从开局即可使用，受能量和有效目标限制。满血时不能急救；空场不能增伤；没有可命中的敌人不能轰炸。失败操作不扣能量、不计施法、不产生字幕。猫薄荷刚生效两秒内，如果所有当前伙伴都已有加成，不能再次付费；新伙伴上场后允许重施，重复施放只刷新时长，不叠加增伤。

急救单只士兵最多回复 69，盾卫最多 210，骑士最多 240。上限避免治疗重骑一次恢复 540，群体治疗也使保留前排比反复损失、补招更有价值。治疗不能复活或恢复基地，因此仍需要及时判断。

一阶轰炸可以清理没有防护的满血投手、法师和枪手，二阶可以击败满血普通士兵；盾卫和骑士仍需部队持续攻击。毛球不会伤害友军或基地，避免直接靠技能拆家。

## 能量选择

双方开局 50，上限 100，击杀恢复能量，没有被动回能或额外长冷却。击杀奖励沿用原配置，主炮和轰炸击杀同样结算，每名敌人只返能一次，超过上限的部分不储存。

- 开局 50：可选择急救或增伤，想使用轰炸还需要积累 20。
- 满能量 100：急救加增伤花费 75，适合维持推进队伍。
- 满能量 100：一次轰炸花费 70，剩余 30；若没有击杀返能，暂时不能接急救或增伤。
- 从零开始：击杀 9 / 10 / 18 名普通士兵，分别足够施放急救 / 增伤 / 轰炸。
- 同阵营只能有一发未落地的轰炸；落地后能量足够即可再次施放。击杀返能可能加快后续施法，实玩需观察连续爆发的频率。

治疗较便宜但需要受伤目标；增伤依赖现有队伍输出；轰炸价格最高、收益依赖敌人密度。价格鼓励根据场面选择，而不是每次能量足够就依次按完全部按钮。

## 判定与电脑使用

轰炸以敌方单位为候选中心，选取半径内敌人最多的位置；人数相同时选择更接近己方基地的威胁，再按单位 ID 保持确定性。落点不追踪目标，落地时重新按实际位置判定。雨伞的远程减伤、功夫猫闪避、刺客隐身和首领登场保护均有效；伤害与其他攻击在同一步结算，正常触发死亡、人口释放、返能及首领击败成就。

电脑遵守相同价格和效果。通常遇到至少四名密集敌人时轰炸；基地受威胁时门槛降为两名。至少三名伙伴低于 65% 生命，或骑士低于 40% 时考虑急救；否则在至少三名未被充分增益的输出单位交战时使用猫薄荷。AI 不免费施法。

## 画面与旧存档

右侧三个按钮显示图标、用途和价格，保留 48×48 像素触控区域。急救用罐头与治疗十字，轰炸有落点预告、落下的毛球和落地反馈；减少动态效果设置下仍能辨认技能状态。战场字幕采用短句，完整效果在玩法指南、按钮说明和读屏信息中可查。

0.18 未完成对局迁移为 0.19，保留资源、部队、研究、随机状态、成就及关卡进度。旧震退不再提供按钮和调用入口，已产生的短暂减速正常结束，过时的震退特效和字幕移除；历史猫薄荷字幕保留当时真实的 50 能量消耗。未知规则版本仍拒绝加载。

未落地轰炸会保存落点、释放时伤害和已过时间，恢复后先暂停；继续后只落地一次。已命中的轰炸不会因刷新页面再次造成伤害。

## 固定策略对照

修改前冻结 0.18 源码和策略于 `analysis/spells-0.19/baseline-source/`、`baseline-policy.mjs`，附 SHA-256 清单。以 30 关、三种相同招募策略（枪手保护、攻城、支援）、种子 1234 进行旧版和新版各 90 场正常资源对照，600 秒截止。新版按当前三技能策略施法，旧版按原震退和猫薄荷策略施法。运行前后校验当前模拟源码指纹，原始结果见 `analysis/spells-0.19/comparison.json`。

| 胜 / 负 / 超时 | 77 / 10 / 3 | 83 / 5 / 2 |
| 胜局中位时长 | 232 秒 | 224 秒 |

新版每关至少存在一种获胜策略。该对照只覆盖一个种子和三种程序策略，不代表真人胜率，也不能证明数值已经全面平衡：仍有长局和两场超时，满血通关偏多。

另做第 1 / 5 / 10 / 15 / 20 / 30 关的枪手策略 × 不施法 / 仅增伤 / 仅急救 / 仅轰炸，共 24 场。第 30 关不施法 504 秒、仅急救 263 秒、仅轰炸 287 秒、仅增伤 386 秒；第 5 关仅轰炸反而从不施法的 303 秒延长到 333 秒。技能会改变战线和增援时序，收益并非每局单调增加；这些单点结果保留在报告中，不用于宣称某一种技能必定最好。

后续试玩重点：35 能量治疗的救场感、70 能量轰炸的攒能等待、击杀回能后的连发频率，以及敌方群体轰炸是否有足够辨识度。当前请求已完成，无阻塞待办，未上传或发布。

先运行 `npm run dev`，默认本地地址 `http://127.0.0.1:5186/`。

```sh
npm test
npm run test:spells
npm run test:browser
npm run test:responsive -- tiny-portrait iphone-14 iphone-landscape desktop
npm run test:boss
npm run build
npm run build:minitool
npm run audit:minitool
node scripts/minitool-diagnostics.mjs
node --experimental-strip-types scripts/spells-balance.mjs
```

Windows PowerShell 可用 `$env:TEST_BROWSER='webkit'` 后运行 `npm.cmd run test:spells`，再移除该环境变量恢复默认 Chromium。历史 `energy-balance.mjs` 等脚本对应旧震退规则，不应用它们覆盖旧报告来表示本版结果。
