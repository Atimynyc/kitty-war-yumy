# 0.18.0 · 小窝荣誉柜与未完对局

2026-10-26。按用户确认实现成就系统和未结束对局的设备本地保存。30 关、16 卡、人口、资源、科技和战斗数值保持原规则。

## 玩家入口

- 首页「小窝荣誉柜」，暂停菜单与结算也可进入；查看时战斗暂停，返回后手动继续。
- 共 24 项：六章旅程、四项经营、两项收藏、八种新兵拿手戏、四项战术。分类和状态可筛选，显示有效累计进度与未招募伙伴。
- 完成 6/12/18/24 项解锁「见习守护喵」「小窝指挥官」「猫咪战术家」「传奇冻干守护者」。称号可佩戴或卸下，在首页和结算显示，无属性奖励。
- 暂停后「保存并返回首页 / 选关」；首页提供「继续未完对局」。只保存一局，新开关卡会先确认替换；已获得的成就与关卡成绩保留。

## 统计与恢复

成就直接观察模拟层真实事件，不以动画、点击或渲染次数计数。枪手伤害扣除过量伤害；伞盾计算实际少损失的生命值；猫砂要求同一枚炸弹命中三名结算后仍存活的敌人；吸盘与拳套按不同受击对象计数；功夫猫只统计实际闪避。刺客必须同一单位先真实触发隐身、显形后伤害敌基地。鼓舞要求生效期间实际造成伤害。混编以实际伤害、承伤、有效治疗与支援贡献判断，招募本身不等于参战。

胜利条件只在真实胜利结算时授予。整备推进要求同一个整备窗口的基地有效伤害达到 500；首领成就要求第 30 关真正击杀胖橘并获胜。普通累计成就在失败、退出时也保留。

存档包含双方基地、粮食、能量、研究与冷却、全部单位与临时状态、弹道、首领登场及蓄力、施法提示、AI 队列与储粮状态、随机数状态、原始种子和本局成就统计。恢复总是暂停，不推进离线时间。原始种子保证继续后重开也保持原对局规则。

同一个 v3 JSON 同时保存成绩、累计成就与战场检查点，恢复时从已应用统计量继续，只累加后续差额，避免重复刷累计。写入合并为一个在途请求和一个最新待保存快照，避免快速操作堆积旧写入。

## 保存边界

- 战斗每两秒触发检查点；招募、升级、施法、暂停、退出和切后台触发保存。异常终止可能损失最近成功保存之后的操作，后台回调也不能保证被系统执行。
- 沿用正式键 `paw-pantry-progress-v1`，数据体版本为 3。经典三关和 v2 主线成绩自动迁移，只补发已有记录能证明的章节徽章。
- 未知档案版本与无法读取的内容保留原值，并提示只读；不兼容的战场快照不恢复，但保留关卡和成就。
- 保存失败明确提示；原生调用失败或超时后不继续排队覆盖，以免不可取消的旧调用晚到。内存中的本局可以继续游玩，但不能宣称已持久化。
- 小红书支持的设备使用现有 `getStorage` / `setStorage` 接口；普通网页回退到浏览器本地存储。两者均为本机缓存，清缓存、换设备或更换网页来源不会自动带走存档。未实现账号云同步。
- QA 使用独立的 `paw-pantry-progress-qa-v3`；注入截图和验收数据不写正式键。
