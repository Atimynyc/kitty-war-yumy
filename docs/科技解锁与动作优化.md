# 0.24.0 · 科技解锁与动作优化

本轮处理三个实玩反馈：科技开放过早、双方基地猫平时不够活泼、兵种攻击动作不明显。

## 科技随伙伴开放

| 研究 | 开放条件 | 研究费用 / 时间 |
| --- | --- | --- |
| 二阶 | 到达第 3 关，毛球投手加入 | 150 猫粮 / 8 秒 |
| 三阶 | 到达第 11 关，玩具大炮加入 | 280 猫粮 / 12 秒 |

资格取决于永久可招募名单，重玩早期关卡仍保留；旧版本继承的高阶伙伴也提供相应资格。每一局仍需支付费用、完成研究。按钮显示开放关卡，标题和读屏说明提供锁定原因；快捷键和直接研究调用使用同一校验，锁定时不扣资源。

战斗规则版本更新为 0.24.0，档案仍为 v5。0.20.0 对局按完整结构重新验证后迁移，保留原兵种名单、已完成科技和已经支付的研究；只限制后续新发起的研究。0.18 / 0.19 的已有迁移继续适用。敌方按原关卡研究节奏运行。

## 持续待机与攻击表现

双方基地猫持续呼吸、缓慢摆头、甩尾、轻抬前爪，并间歇眨眼、抖耳和嗅闻；双方动作错开。自定义外观预览同步使用相同动作。脚掌和阴影固定，暂停、续玩、结束与系统减少动态设置保持一致。

普通攻击的预备动作窗口扩大至 0.28 秒，接触姿态保留 0.12 秒，再平滑回到待机，总时长 0.48 秒。强化士兵挥击、盾推、投手拉弓、法师挥棒、枪炮后坐、拳套冲拳等不同动作；近战增加短促挥击弧线。降低攻击时受击后仰对前冲的抵消，士兵与刺客出手增加向前伸臂。伤害时刻、攻击间隔、移速、技能判定和兵种数值未调整。

所有动作由战斗时间和实际出手时间驱动，不新增随机战斗事件；减少动态时关闭位移、旋转和挥击弧线。

## 本轮验证

- 155 项规则与存档测试通过，包含全 30 关科技资格、重玩与继承、锁定不扣费、旧对局研究保留及损坏档案拒绝。
- Chromium / WebKit 均通过科技解锁专项、基地猫待机专项和我方 16 种 / 敌方 8 种兵种的真实连续动作检查，覆盖接触停留、回弹、暂停及减少动态。待机检查额外验证手机下摆头和尾巴的可见幅度。
- 双引擎均在独立前台页面完成 1× / 2× 实际播放检查，验证连续出手、同时受击时的动作可见性和播放倍率。
- Chromium 原动作专项、自定义猫专项、新兵种专项通过。检查实际截图和连续帧，产物分别在 `test-results/animations/`、`cat-editor/`、`specialists/`、`cat-idle/`、`attack-readability/`。
- Chromium 17 种窗口尺寸响应式回归通过；科技锁定提示另在 320px、390px、横屏与桌面核对。
- 标准 develop-web-game 客户端正常资源招募三名士兵、施法并推进约 26 秒，查看截图和文本状态；产物 `test-results/skill-tech-motion-combat/`。
- 正式构建、小工具构建、静态审计，以及 Chromium / WebKit 生产与能力降级四条受限加载诊断通过。

前十关使用现有固定策略做了 50 场正常资源探测：39 胜、1 负、10 超时。超时均为前两关固定策略只保留四名士兵；另用持续招募一阶士兵的策略，前两关分别在 149 / 152 秒获胜。第 3–10 关均存在正常资源通关记录。报告保留在 `analysis/unit-unlocks-2026-10-26/tech-gates-0-24*.json`，包含源码指纹；这只是有限策略探测，不代表真人胜率或完整平衡验收。

真实手机、小红书平台模拟器和实际 Chrome 61 尚未验证。本轮未发布或上传。

可复跑：`npm test`、`npm run test:unlocks`、`npm run test:cat-idle`、`npm run test:attack-readability`。后三个浏览器专项使用 `TEST_BROWSER=webkit` 切换引擎。
