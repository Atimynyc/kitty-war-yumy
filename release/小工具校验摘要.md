## 修复内容

1. 增加专用离线构建：使用项目已有构建依赖生成外置 IIFE 经典脚本，目标为 ES2017、Chrome 61、iOS 18.4；入口引用均为相对路径。
2. 将战场 SVG 从 XHR 加载改为图片元素加载。使用本地生成的小型 SVG，无远程资源。
3. 小工具构建从 Phaser 3.90.0 源码去除 XHR、全屏、鼠标锁定、无关设备探测和 WebGL 渲染路径，保留 Canvas 2D。构建器检查 Phaser 版本，升级后须重新审查适配。
4. 为实际使用的 `Object.fromEntries` 提供局部实现；移除 `replaceChildren` 依赖；`ResizeObserver` 不可用时使用窗口和游戏布局事件。
5. 转换 CSS inset、Grid gap、place-items；为 Flex gap 进行实际布局检测并提供 margin 回退；将 `:has()` 和容器查询转为界面状态 class；补充宽高、颜色、焦点与安全区回退。原生安全区、容器注入变量及标准 Web 环境均有处理。
6. 存档优先使用 9.46+ 的 Storage，处理同步/异步版本读取、旧数据迁移、串行保存及失败提示。原生读取失败时禁止覆盖未读到的旧记录；低版本或方法不可用时才使用带异常处理的浏览器存储。
7. 9.49+ 优先读取窗口信息，使用容器尺寸、安全区及顶部按钮区域调整布局；尺寸变化时重新读取。不满足条件或接口失败时使用 Web 视口回退。

源码修改前的副本位于 `.tmp/minitool-backup/`。战斗数值与核心规则未修改。
